## What exists

`StatsModels.ipynb` performs exploratory data analysis and an ordinary least squares (OLS) regression relating rental value to property area using `dataset.csv`.

The repository has no dependency manifest, dataset provenance record, automated tests, validation split, or deployment artifact.

## Decision

Retain only as a labeled statistics/EDA learning reference, or archive it after owner review. Do not use it for valuation, pricing, or other real-world decisions.
